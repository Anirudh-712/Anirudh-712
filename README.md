### What I'm building

**[OnlyKrida](https://onlykrida.com)** — a talent discovery platform for Indian athletes.

Most young athletes in India never get seen. Not because they lack ability, but because scouting runs on personal networks and proximity to a handful of cities. If you're a 16-year-old winger in a district town, the pipeline doesn't reach you.

OnlyKrida is an attempt at a different route: verifiable performance data instead of who-knows-whom.

- **Standardised fitness testing** — Yo-Yo IR1, sprints, agility, vertical jump, scored against age and sport benchmarks
- **Coach-verified results** carry higher trust weight than self-reported ones
- **Opportunity listings** for trials, tournaments and academy places
- **Athlete profiles** built around evidence, not highlight reels alone

Currently in early access. React Native (Expo) + TypeScript + Supabase.
